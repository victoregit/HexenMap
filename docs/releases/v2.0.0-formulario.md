# Formulário da release 2.0.0

- **Repositório:** `victoregit/HexenMap-Releases`
- **Tag:** `v2.0.0`
- **Título:** `Hexen Map 2.0.0 — Expanded Maps & World Map Navigation`
- **Descrição:** copiar o conteúdo bilíngue de [v2.0.0.md](v2.0.0.md), com português primeiro e inglês em seguida. Usar o Markdown original, sem escapar títulos ou negrito.
- **Destino da tag:** branch padrão do repositório de releases. O código de desenvolvimento fica no repositório principal, na `develop`.
- **Preparação:** salvar como rascunho enquanto a validação em jogo dos mapas novos estiver pendente. O minimapa já recebeu aprovação local.

## Anexos

| Arquivo | Origem local | Função |

| `HexenMap-2.0.0-Setup-x64.exe.sha256` | `dist/installer/` | Integridade do instalador. |

| `HexenMap-2.0.0-Windows-x64.zip.sha256` | `dist/atual/` | Integridade do ZIP. |

O executável isolado não substitui o pacote completo para novos usuários.
Os arquivos automáticos **Source code (zip)** e **Source code (tar.gz)** do GitHub
são arquivos do repositório e não são o aplicativo para Windows.

## Escopo

A versão principal foi elevada de 1.0.7 para 2.0.0 pela ampliação dos mapas e da
navegação global. IDs e coletas continuam compatíveis. O assistente pessoal de
calibração do AutoMark não faz parte desta entrega. A preparação dos anexos não
publica a release automaticamente.
