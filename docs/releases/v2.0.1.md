- Revalidação do terreno com até três imagens nativas associadas a uma localização previamente confirmada, quando a referência global demora a renovar.
- Verificação dos pixels atuais antes de exibir os marcadores, preservando os critérios geométricos e rejeitando correspondências incompatíveis.
- Descarte das referências ao perder foco, mudar de contexto ou receber uma correção incompatível.
- Diagnóstico com o estado das referências nativas e o tempo desde a última verificação.

## English

Hexen Map 2.0.1 introduces a targeted fix for intermittent marker disappearances on the minimap.

### Minimap

- Terrain revalidation using up to three native images tied to a previously confirmed location when the global reference is slow to refresh.
- Current pixels are verified before displaying markers, preserving geometric validation criteria and rejecting inconsistent matches.
- References are discarded on focus loss, context changes or an incompatible correction.
- Diagnostics include native reference status and time since the last verification.

### Compatibility and validation

- Progress, profiles and map features from version 2.0.0 remain available.
- AutoMark's chest-opening and reward detector has been preserved; the feature remains in beta.
- 140 relevant tests passed. Real gameplay stability validation is still pending; this fix does not guarantee that all flickering has been eliminated.
- The personal AutoMark calibration wizard is not included yet.

### Downloads

- **Installer:** `HexenMap-2.0.1-Setup-x64.exe`.
- **Portable:** `HexenMap-2.0.1-Windows-x64.zip`. Extract the entire ZIP before running the app.
- **Source Code:** `HexenMap-2.0.1-Source-Code.zip`.
- All downloads include `.sha256` files for integrity checks.

Requires 64-bit Windows 10/11. Close Hexen Map before updating and preserve your progress files.
