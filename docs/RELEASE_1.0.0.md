# Hexen Map 1.0.0

- Versão visível no rodapé do painel, tanto em Itens quanto em Ajustes.
- Correção da faixa vazia acima das categorias ao rolar uma lista curta.
- Launcher com animação, verificação automática no repositório
  `victoregit/HexenMap-Releases` e pedido de administrador antes da verificação.
- Instalador por usuário com atalho no menu Iniciar e preservação das coletas
  e preferências existentes nas atualizações e reinstalações.

Arquivos da Release: `HexenMap-1.0.0-Setup-x64.exe` e seu `.exe.sha256`.
O número 1.0.0 não altera os limites de cobertura nem remove a indicação beta
de funcionalidades ainda em validação, como o AutoMark.

Publicada em 10/11/2026: https://github.com/victoregit/HexenMap-Releases/releases/tag/v1.0.0

Instalador e checksum conferidos na API pública do GitHub. O código do launcher
detectou a versão 1.0.0 ao simular uma instalação 0.4.1-beta.1.
